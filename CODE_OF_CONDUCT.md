# Code of conduct

This is a solo side project, but if you're filing issues, commenting, or opening a PR:

- Be civil. Disagree about the code all you want, don't make it personal.
- No harassment, hate speech, or targeting people rather than problems.
- Keep discussion on topic for the repo (bugs, features, the code itself).

Aetheria itself is an unmoderated local roleplay tool, whatever you generate in your own instance is between you and your LLM provider. This file is about how people treat each other in this repo, not about content policy for the app.

Violations get a warning, then a block. There's no committee, it's just me.
